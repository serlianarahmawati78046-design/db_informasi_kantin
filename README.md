# db_informasi_kantin
Basis data db_informasi_kantin dirancang untuk mengelola dan mengintegrasikan seluruh operasional transaksi serta manajemen di kantin sekolah secara digital. Sistem ini mencakup pengelolaan menu makanan dan minuman, data pelanggan (siswa), riwayat pemesanan/transaksi, hingga penjadwalan piket kasir.
